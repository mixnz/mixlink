# Docs Index

Read only the file you need. Every doc ≤ 300 lines.

| File | When to read |
|---|---|
| `STATUS.md` | Session start: what is done, what is next. |
| `roadmap/README.md` | Picking the next task; phases and row rules. Then read one phase file. |
| `architecture/overview.md` | Touching data flow between crates or adding a crate. |
| `architecture/latency-budget.md` | Any change on capture/encode/net/decode/render/input path. |
| `architecture/protocol.md` | Touching packets, discovery, pairing, encryption. |
| `conventions/coding.md` | Before writing Rust code in a new area. |
| `conventions/file-limits.md` | When a file approaches its size limit. |
| `conventions/docs-writing.md` | Before writing or editing docs/specs. |
| `decisions/` | ADRs. Read the one relevant to the question; never re-litigate. |
| `specs/` | Feature specs. Each links to its plan in `docs/plans/` (local only). |
| `compat/anti-cheat.md` | Anti-cheat launch results and the user warning; touching drivers or the installer. |

`docs/plans/` is generated by the writing-plans skill and is gitignored.
